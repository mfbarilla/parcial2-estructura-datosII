# Parcial 2 - Tienda en línea

Proyecto de Estructuras de Datos. Genera 50 productos, los ordena con Merge Sort, Quick Sort e Insertion Sort por precio y por calificación, y prueba la búsqueda binaria por id y la búsqueda lineal por nombre.

Para ejecutarlo se necesita Python 3:

    python main.py

Archivos:

- producto.py: clase Producto
- generador.py: genera los 50 productos
- ordenamiento.py: los tres algoritmos de ordenamiento
- busqueda.py: búsqueda binaria y búsqueda lineal
- main.py: ejecuta las pruebas y muestra los tiempos
